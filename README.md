## About Me

I am a developer who writes in whatever language the problem demands — from bare-metal C to Go microservices to C# desktop apps. I gravitate toward systems-level work, network tooling, and clean CLI utilities.

- Building tools that solve real problems, not demos
- Comfortable dropping down to pointers and memory when needed
- Language polyglot: C, C++, C#, Go, Java, Python, JavaScript, Lua
- Interested in networking, security tooling, and backend infrastructure
