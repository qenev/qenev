# About Me

I'm a developer who writes in whatever language the problem demands — from bare-metal C to Go microservices to C# desktop apps. I gravitate toward systems-level work, network tooling, and clean CLI utilities.

I've built password generators in C, binary search trees in C++, REST APIs in Go, port scanners in Java, file organizers in Python, weather CLIs in JavaScript, and config systems in Lua. I pick up languages fast and go deep when it matters.

I care more about writing code that actually works than code that looks impressive on a resume.
